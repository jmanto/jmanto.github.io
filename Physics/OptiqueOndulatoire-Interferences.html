Interférences à deux sources (fentes de Young)

Fronts d'onde circulaires émis par deux sources et amplitude résultante en un point détecteur.
Chargement de Pyodide…
source 1 (bleu) — source 2 (vert) — détecteur (rouge)
amplitude 1 — amplitude 2 — somme
Calcul effectué en Python (NumPy) via Pyodide ; rendu sur <canvas>. Le double-clic pour positionner le détecteur, utilisé dans le script d'origine, est remplacé par deux sliders.
